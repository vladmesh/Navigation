# 2026-10-23 · epic 01 · architect-plan

Конспект планирования эпика 01 «Сетка координат в зоне отрисовки». ADR:
[docs/adr/0001-coordinate-grid.md](../adr/0001-coordinate-grid.md).

## Что посмотрели в коде

- Основная карта — `Drawing/uberpainter.cpp` (`UberPainter`, создаётся в `mainwindow.cpp:56`).
  Сцена пересоздаётся раз в секунду: `updateView()` → `graphicsScene->clear()` →
  `drawCoordinatesNet(minX, minY, maxX, maxY)`.
- `drawCoordinatesNet`: фиксированный шаг 50 м по bbox объектов ±500 м; баг — `maxX -= 50`
  дважды, `maxY` не сдвигается; подписи — 8 равных долей видимой области, не у линий.
- `updateCoordinates()` дублирует код подписей и при пане удаляет все текстовые элементы
  сцены (включая подписи линейки расстояния).
- Ось Y инвертирована (`scale(1,-1)`), шрифт масштабируется через `transform().m11()`,
  при зуме подписи не обновляются.
- `MyGraphicView` (схема судна) — `drawGrid` закомментирован, вне скоупа.
- В `main` нет тестового проекта и CI; они в ветке `ci/minimal` (`Test/unit/unit.pro`,
  `pr-ci.yml`), которую ведёт другой агент.

## Решения человека

1. Только основная карта `UberPainter`; схему судна не трогаем.
2. Координаты — метры UTM (easting/northing), не lat/lon.
3. Адаптивный шаг по ряду 1–2–5×10ⁿ, ~5–10 линий на видимую область.
4. Подписи в метрах прямо у линий, читаемые при инверсии Y и любом зуме.
5. Переключатель вкл/выкл не нужен — сетка всегда включена.
6. Unit-тест на функцию расчёта шага (чистая функция без Qt GUI, для CI).
7. Исправить баг границ; убрать дублирование с `updateCoordinates`.

## Решения архитектора

- Математика сетки — `GridMath` (`Drawing/gridmath.h/.cpp`, без Qt): `niceStep`,
  `gridLines`, `labelDecimals`. Шаг по короткой стороне видимой области, ячейки квадратные.
- Сетка строится по видимой области (+1 шаг), а не по bbox объектов — баг границ уходит
  вместе со старым кодом.
- Подписи — `QGraphicsSimpleTextItem` с `ItemIgnoresTransformations`: не зеркалятся и не
  масштабируются без ручного `mirrorTransform`/`m11()`.
- Элементы сетки в отдельной группе; перерисовка не трогает треки и линейку.
- Перерисовка: раз в секунду, на пане, после зума колесом, на ресайзе.
